# Titanic Survival Prediction

## Objective
Predict whether a passenger survived the Titanic disaster.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Machine Learning Algorithm
- Logistic Regression

## Results
Model achieved approximately 82% accuracy.

## Visualizations
- Survival Distribution
- Correlation Heatmap
- Confusion Matrix
