💳 Credit Card Fraud Detection Dashboard

Machine Learning Project using Random Forest

📂 Upload Transaction File

Upload a CSV file containing credit card transactions. The system will classify each transaction as Genuine or Fraudulent.



📌 About this Project

  • ✔ Detects fraudulent credit card transactions
  • ✔ Random Forest Machine Learning Model
  • ✔ Handles class imbalance using SMOTE
  • ✔ Batch prediction using uploaded CSV files
  • ✔ Displays analytics dashboard
  • ✔ Download prediction results as CSV

🛠 Technologies Used

Python • Flask • Pandas • NumPy • Scikit-learn • Matplotlib • Seaborn • Joblib
